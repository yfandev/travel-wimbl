## Caveats (read before quoting the number)

- **Ceiling.** Memory-on passed every target check (SD 0), so the normal-approximation interval is rough. Per check, 15/20 → 20/20 for both `names_official_resale` and `kickoff_risk` has a two-sided Fisher exact p ≈ 0.047 each: suggestive, not conclusive, at n = 20 per arm.
- **The lessons mirror the acceptance criteria.** They were written from the verifier's failed checks, and the same checks grade the held-out trips. The result shows that criteria-derived lessons learned on one club transfer to other clubs' trips; it does not show improvement on anything the checks don't measure.
- **The gate promoted a bundle and hid a per-lesson regression.** On the benchmark, `kickoff_risk` rose 0.00 → 1.00 but `names_official_resale` fell 0.50 → 0.25; the combined target rate still cleared the threshold. The brief asks for one isolated change per evaluation, so the real gate should evaluate each lesson separately. (On held-out trips `names_official_resale` rose 15/20 → 20/20, so the benchmark drop may be noise at 4 runs per arm.)
- **Cost.** Memory-on used more output tokens (mean 2318 vs 1390, about 1.7×) and took longer (p50 8.5 s vs 4.8 s). Cost per verified success is not computable yet: Lightning has no confirmed Crusoe price.
- **Not a production agent.** The tickets agent here is the measurement harness's, not Patrick's trip children; one task type, fixture evidence, one benchmark trip.
- Held-out trips B and C, the grader, and the primary metric were not changed after the v1 diagnosis.
